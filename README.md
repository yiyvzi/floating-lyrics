# Floating Lyrics 1.0.0

Floating Lyrics 是 Windows 悬浮歌词窗口，支持 QQ 音乐和网易云音乐，也可以独立显示本地 LRC。

## 启动

日常使用请双击 `start.vbs`，它直接打开悬浮窗，不弹出命令行窗口。新环境首次安装依赖或遇到启动错误时，使用 `start.bat` 查看提示。

也可以将项目里的「Floating Lyrics」快捷方式（`.lnk`）复制到桌面。快捷方式使用本机项目中的文件，请保留原项目目录。

1. 双击项目里的 `start.bat`。首次启动或升级时，脚本会从 PyPI 安装界面和 Windows 媒体会话组件，需要联网。
2. 在音乐播放器开启系统媒体控件（SMTC）并播放歌曲。右上角「⋯」可选择「重新播放示例歌词」，再用「跟随播放器」返回。
3. 点击右上角「×」或菜单中的「退出 Floating Lyrics」彻底关闭。快捷键隐藏窗口时，程序会继续运行，以便通过同一快捷键重新显示。

从源码运行需要 64 位 Python 3.11–3.15，推荐使用本项目已测试的 Python 3.14。安装后双击 `start.bat`。

## QQ 音乐

1. 使用 QQ 音乐 Windows 桌面版，在「设置 → 常规设置 → 通知」开启「显示系统媒体传输控件（SMTC）」，然后播放一首歌。
2. 便携版请先完整解压，再打开 `Floating Lyrics.exe`。便携版已包含所需运行组件，无需安装 Python 或 QQ 音乐插件。
3. Floating Lyrics 会自动用歌名、歌手和可用的时长、专辑信息在 QQ 音乐匹配曲目，取得同步歌词和已有译文。找不到可靠匹配时尝试 LRCLIB。已缓存的同步歌词可离线使用。
4. 切歌、播放、暂停和跳转由 QQ 音乐客户端提供。底部按钮变灰时，请先确认 QQ 音乐正在播放且 SMTC 已开启。两个播放器同时存在时，优先使用 Windows 当前的受支持会话。

## 在网易云音乐里使用

1. 开启 SMTC 并播放歌曲。悬浮窗显示歌名、歌手和播放状态，专辑有数据时显示。浏览器等其他软件的媒体会话会被忽略。
2. 悬浮窗先尝试匹配本地 LRC 和以前成功查到的歌词。有网易云曲目 ID 时，优先向网易云查询原文和译词，缺词时再查询 AMLL 和 LRCLIB。没有曲目 ID 时，会自动用歌名和歌手查询 LRCLIB，并用可取得的专辑、时长核对版本。
3. 成功匹配的同步歌词和配套译词会保存在本机，下次启动后可离线复用。仍可通过「⋯ → 重新在线查找歌词」跳过缓存再查一次。
4. 如果显示「无系统进度」，打开「⋯ → 设置手动进度」，输入网易云当前已播放的秒数，例如 `1:15` 输入 `75`。确认后，歌词计时会跟随当前歌曲的播放和暂停。拖动网易云进度条或重播后请重新对齐。切歌时会清除上首歌的对齐和临时导入的歌词。

### 本地歌词来源

程序会尝试读取网易云目录下 `Lyric` 或 `Cache\Lyric` 内的标准 `.lrc` 文件。已测试的网易云版本 3.1.43.205627 未找到可可靠匹配的独立缓存歌词。也可在项目里自行创建 `lyrics` 文件夹，把歌词放进去，文件内带有 `[ti:歌名]` 和 `[ar:歌手]`，或者命名为 `歌手 - 歌名.lrc`。这样每次识别到同一曲目即可自动加载。临时导入或粘贴的歌词只用于当前歌曲。

### 中文翻译

- 「⋯ → 显示中文翻译」默认开启。歌词源提供配套中文译词时，译文会显示在对应原文下方，并一起高亮和滚动。
- 歌词库明确标记为纯音乐时，歌词区中央显示「纯音乐 · 请欣赏」。曲库缺少同步歌词时显示「静听此刻」，连接失败时显示「歌词查询失败」。

### 独立使用本地歌词

1. 点击「⋯」，选择「导入 LRC 文件」或「粘贴 LRC 文本」。
2. 若歌曲已经播放，在菜单中选择「设置手动进度」，输入歌曲已播放的秒数。若从头播放，则从默认的 0 秒开始。
3. 在网易云音乐播放歌曲，并在歌词窗口菜单中选择「开始手动计时」。暂停或跳转歌曲后，可用同一菜单重新对齐。

如已进入网易云跟随模式，先选「重新播放示例歌词」，再导入自己的 LRC，即可使用独立计时。

支持 UTF-8、带 BOM 的 UTF-16 和常见的 GB18030 歌词，兼容 `[00:12.50]`、`[00:12.500]`、同一行多个时间戳、歌曲标签和 `offset` 标签。

## 窗口操作

- 「⋯ → 调整外观 → 主题」可切换经典暖金、深海青、奶油蓝、雾橄榄和深莓红。切换时可实时预览，点 OK 保存，点取消恢复原主题。经典暖金可自定义背景颜色，各渐变主题均可调不透明度。

- 按住顶部歌曲信息区域拖动。拖动窗口边缘或角落可缩放。
- 用鼠标滚轮浏览完整歌词。停止滚动 5 秒后，窗口会自动回到当前句。可在「⋯ → 调整外观」修改等待时间，设为 0 可关闭自动恢复。也可点击「恢复自动跟随」立即回到当前句。
- 主窗口底部可控制上一首、播放或暂停、下一首。「⋯ → 从头播放」可重播当前曲目。双击歌词可跳到对应时间，也可在「⋯ → 跳转播放进度」输入秒数。相应操作需要播放器通过 SMTC 开放控制。
- 在「⋯」菜单调整背景颜色、不透明度、歌词字号和行距，或锁定窗口的位置和大小。

| 全局快捷键 | 操作 |
| --- | --- |
| Ctrl + Alt + F9 | 显示或隐藏 |
| Ctrl + Alt + F10 | 开启或关闭点击穿透 |
| Ctrl + Alt + F11 | 恢复自动跟随 |

点击穿透开启后，用 **Ctrl + Alt + F10** 恢复鼠标操作。若 Windows 无法注册穿透快捷键，软件会禁用穿透开关。可用记事本修改 `defaults.json` 中的 `hotkeys`，保存后重启生效。快捷键由 Ctrl、Alt、Shift 或 Win 和字母、数字或 F1 至 F24 组成。

在「⋯ → 调整外观」中点击 **OK** 后，背景颜色、不透明度、歌词字号和行距会自动保存。窗口位置、宽高和「显示中文翻译」开关也会在下次启动时恢复。原来的显示器不可用时，窗口会回到可见屏幕。

## 运行自测

在项目文件夹打开 PowerShell，运行以下命令。测试会短暂打开窗口并自行关闭。

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

测试覆盖 LRC 时间戳、歌词切换与滚动、全局快捷键、点击穿透、媒体时间轴校验、手动对齐随播放状态暂停和恢复、切歌清除旧歌词，以及公开歌词匹配。

## 开发进度

- 本机已在网易云音乐 3.1.43.205627 上验证 [BetterNCM 1.3.4](https://github.com/std-microblock/chromatic/releases/tag/1.3.4) 和 [InfLink-rs 3.4.0](https://github.com/apoint123/inflink-rs/releases/tag/v3.4.0) 可以提供曲目 ID、实际播放进度和总时长，播放、暂停和跳转均已实测。其他电脑或网易云升级后的兼容性需要重新验证。
- Floating Lyrics 通过 InfLink-rs 发布的时间轴同步，按曲目 ID 优先从网易云取词，并保留 [AMLL](https://github.com/amll-dev/amll-ttml-db) 和 LRCLIB 作为备选。没有插件时，本机这版网易云自身只提供曲目信息和播放状态，可继续使用手动对齐。
- 外观与窗口状态已支持自动保存。第三阶段还计划增加图形化快捷键设置和开机启动选项。
